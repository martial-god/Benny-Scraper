# Benny-Scraper v3.0.0

## Correcting comic archive support

I never actually tested CBR, CB7, CBT, or CBA files, assuming they would work like CBZ. That was incorrect. Benny-Scraper wrote ZIP archives for all of those options and only changed the file extension. The comic archives generated by older versions were really CBZ-compatible ZIP files, not genuine RAR, 7z, TAR, or ACE files. PDF and EPUB generation were separate and are not affected by that mistake.

This is a breaking change to the available format options: manga output is now PDF or CBZ only. Use `benny-scraper -e 1` to select CBZ, or `benny-scraper -e 0` for PDF. Update scripts that use the removed numeric format choices and reset a saved legacy manga default before downloading new books.

## Existing books

- Back up your database and generated books before updating. You do not need to clear the database.
- Updates can read old ZIP-based comic archives regardless of their extension. When chapter images are written, the result uses `.cbz`, and an original file with another extension is preserved. An existing sibling `.cbz` is not overwritten by this conversion.
- Genuine RAR, 7z, TAR, and ACE archives need conversion with a suitable external tool; renaming them is not enough.
- CBZ updates preserve unaffected chapter entries and replace updated chapters. The original saved archive is required; missing archives are reported rather than silently replaced with only the newly downloaded chapters.
- Legacy database enum values remain readable for compatibility. Changing the recorded file type with `-x` does not itself convert a file.

## Image processing and file safety

- Replaced SixLabors.ImageSharp with Magick.NET-Q16-AnyCPU 14.17.2. Contributors do not need an ImageSharp build-time license key. Magick.NET.Core is included transitively rather than referenced separately.
- Migrated WebP conversion, PDF image processing, and CBZ format detection. Lossless and lossy WebP conversion retain orientation handling, size limits, animation rejection, and protection against overwriting an existing output.
- Temporary chapter downloads are cleaned up after the generation/update operation, including failure paths. Cleanup failures do not hide the original generation error.
- Temporary output files are used before replacing existing EPUB, PDF, or CBZ files. Invalid or incomplete image input fails rather than silently dropping pages from a replacement book.

## Validation

The Windows Release build and self-contained Windows x64 publish passed without warning suppression. All 65 tests passed, including image conversion and archive-update regression tests. Linux and macOS execution were not tested locally; the release workflow publishes separate builds for those platforms.
